### Exercícios propostos sobre Strings (Cadeias de Caracteres)

**1.** Escreva uma função que receba uma string e conte quantas vogais (a, e, i, o, u) ela possui, ignorando a diferença entre maiúsculas e minúsculas.

**2.** Crie um programa que solicite uma frase ao usuário e substitua todas as ocorrências da letra "a" pelo símbolo "*", utilizando o método `replace()`.

**3.** Desenvolva uma função que valide se uma string digitada pelo usuário contém apenas dígitos numéricos.

**4.** Escreva um código que receba uma string e verifique se ela começa com a palavra "Python" e termina com um ponto final.

**5.** Utilizando o fatiamento, crie uma função que receba uma string e retorne apenas os caracteres localizados nos índices ímpares.

**6.** Crie um programa que receba um nome completo e imprima as iniciais de cada nome em letras maiúsculas (Exemplo: "João Araujo Ribeiro" vira "JAR").

**7.** Escreva uma função que receba uma frase e retorne o número total de palavras que ela contém, utilizando o método `split()`.

**8.** Implemente um programa que limpe espaços extras no início e no final de uma string inserida pelo usuário e, em seguida, converta todo o texto para letras maiúsculas.

**9.** Escreva um código que receba duas strings e verifique se a segunda é uma "substring" da primeira (se está contida nela).

**10.** Crie um gerador de e-mails simples: peça o nome e o sobrenome de uma pessoa e gere um endereço no formato nome.sobrenome@empresa.com.br, tudo em letras minúsculas.

### Exercícios sobre Arquivos

**11.** Escreva um programa que leia o arquivo "nomes.txt" criado na Seção 6.4 e imprima na tela apenas os nomes que começam com a letra "J".

**12.** Crie um programa que leia um arquivo de texto e conte quantos caracteres ele possui no total, incluindo espaços e quebras de linha.

**13.** Desenvolva um script que leia um arquivo de texto e gere um novo arquivo chamado "copia_maiuscula.txt", contendo o mesmo conteúdo, mas com todas as letras convertidas para maiúsculas.

**14.** Escreva um programa que solicite ao usuário cinco frases e as salve em um arquivo chamado "minhas_frases.txt", uma frase por linha.

**15.** Crie um programa que leia o arquivo "tabelaSenoCosseno.txt" (do Programa 6.16) e calcule a média dos valores da coluna "Seno".

**16.** Implemente um sistema de numeração de linhas: leia um arquivo qualquer e escreva seu conteúdo em um novo arquivo, adicionando o número da linha no início de cada uma (Exemplo: "1. Conteúdo da linha").

**17.** Escreva um programa que busque por uma palavra específica dentro de um arquivo de texto e informe em quais linhas (número da linha) essa palavra foi encontrada.

**18.** Crie um programa que leia dois arquivos de texto diferentes e gere um terceiro arquivo que seja a junção (concatenação) dos dois.

**19.** Desenvolva um script que leia um arquivo contendo uma lista de números (um por linha) e grave em outro arquivo apenas os números que forem pares.

**20.** Escreva um programa que leia o conteúdo de um arquivo e o exiba na tela de trás para frente (da última linha para a primeira).
